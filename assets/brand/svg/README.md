# EmbeddedTestBench — Vector Brand Assets

All artwork in this package is supplied as editable SVG vector files.

## Contents
- `logos/`: horizontal, compact, and monochrome wordmarks
- `icons/`: light/dark/blue app icons, favicon, social icon, glyph and monochrome glyph
- `instrument-icons/`: PSU, J-Link, oscilloscope, DMM, BLE, RF and temperature icons
- `headers/`: GitHub repository header and website header

## Suggested use
- GitHub social preview / repository header: `headers/embeddedtestbench-github-header.svg`
- Website navigation: `logos/embeddedtestbench-logo-horizontal.svg` or `headers/embeddedtestbench-website-header.svg`
- Small icon / favicon: `icons/embeddedtestbench-favicon.svg`
- Dark UI: `icons/embeddedtestbench-app-dark.svg`
- Light UI: `icons/embeddedtestbench-app-light.svg`

The wordmark uses common system sans-serif font fallbacks. For exact typography across environments, convert the text to paths in a vector editor before final production. SVGs scale without rasterization.
