# Cppcheck suppressions for the MISRA C:2012 check (.github/workflows/style.yml, #379).
#
# One entry per rule and file, each preceded by its reason. Every entry is also
# a row of the deviation table in ETB-STD-002 §72.5, under the ID given here;
# change the two together. The table says which entries are deviations from a
# rule, which are Cppcheck false positives, and which follow from what the check
# can see.
#
# Cppcheck reports an entry that no longer matches anything only when run with
# --enable=information (unmatchedSuppression). Run it that way after changing
# the code an entry covers, and remove what no longer matches.

# --- Scope -------------------------------------------------------------------

# SCOPE-01: the dongle check reads the firmware against the stand-ins for nRF5
# SDK headers in its test support, so that SDK names resolve. The stand-ins
# keep the SDK's own names and are vendor API, outside ETB-STD-002 (§1.3).
*:firmware/nordic_dongle/test/support/include/*

misra-c2012-17.1:firmware/nordic_dongle/src/cmd_parser.c
# DEV-MISRA-02, Rule 21.6: the formatter builds each line with vsnprintf(),

misra-c2012-21.6:firmware/nordic_dongle/src/cdc_acm.c
# DEV-MISRA-02, Rule 21.6: a reply body is built with vsnprintf() and a

misra-c2012-21.6:firmware/nordic_dongle/src/cmd_parser.c

misra-c2012-8.9:firmware/nordic_dongle/src/main.c

misra-c2012-20.7:firmware/nordic_dongle/include/protocol.h

misra-c2012-20.10:firmware/nordic_dongle/src/cmd_parser.c

misra-c2012-11.4:firmware/s2lp_kit/src/hal_l053.c
# DEV-MISRA-09, Rule 11.4: the Cortex-M vector table holds the initial stack
# pointer (&_estack, a linker symbol) and the handler addresses as words, as
# the hardware reads them.
misra-c2012-11.4:firmware/s2lp_kit/src/startup.c
# FP-02, Rule 17.3: hal_irq_save() and hal_irq_restore() hold the only inline
# assembly (MRS/MSR PRIMASK, CPSID I), encapsulated as Directive 4.3 asks;
# Cppcheck reads each __asm statement as a call to an undeclared function.
misra-c2012-17.3:firmware/s2lp_kit/src/hal_l053.c
# FP-03, Rule 2.7: hal_irq_restore()'s parameter is the input operand of its
# MSR PRIMASK statement, a use Cppcheck does not see.
misra-c2012-2.7:firmware/s2lp_kit/src/hal_l053.c

# .bss between linker-defined bounds (_sdata/_edata, _sbss/_ebss). Each pair
# delimits one region; C sees the two symbols as distinct objects.
comparePointers:firmware/s2lp_kit/src/startup.c
